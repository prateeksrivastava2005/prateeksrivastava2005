<details>
<summary>Snake not visible? — Fixed snake.yml setup</summary>

The automated workflow `.github/workflows/snake.yml` runs daily at midnight UTC and automatically updates the snake animation:

```yaml
name: Generate Snake

on:
  schedule:
    - cron: "0 0 * * *"
  workflow_dispatch:
  push:
    branches:
      - main

jobs:
  snake:
    runs-on: ubuntu-latest
    permissions:
      contents: write

    steps:
      - uses: actions/checkout@v4

      - uses: Platane/snk@v3
        with:
          github_user_name: prateeksrivastava2005
          outputs: |
            dist/github-snake.svg
            dist/github-snake-dark.svg?palette=github-dark

      - name: Push snake to output branch
        uses: JamesIves/github-pages-deploy-action@v4
        with:
          branch: output
          folder: dist
          clean: false
```

Trigger it manually anytime under **Actions → Generate Snake → Run workflow**.
